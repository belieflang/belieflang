Language reference →

TypeScript runtime

Snapshots and provenance inspection. V3 factual-memory APIs retain historical values, track conflicts, and check evidence and authorization before actions.

Memory and action checks →

Use OpenAI or Jev for inference, or connect another model through the TypeScript inference adapter.

Current limitations
  • V3 factual memory and decision guards are TypeScript APIs, not .bel syntax.
  • Fact verification and action authorization come from the host application.
  • Change history is bounded; saved state can grow. Automatic archival is not implemented.
  • General dependency tracking, selective invalidation, and broader caching remain research directions.

Quick start

Node.js 22 or later.
