# bel-providers

Inference provider integrations for [BeliefLang](https://github.com/belieflang/belieflang):
`JevInferAdapter` (TypeSafe Jev), `OpenAIInferAdapter`, `HttpTransport`, and mockable
transport abstractions for deterministic contract tests.

Live provider calls require API keys and may incur costs.

This crate is part of the BeliefLang workspace and is versioned in lockstep with
[`bel-syntax`](https://crates.io/crates/bel-syntax),
[`bel-runtime`](https://crates.io/crates/bel-runtime), and the
[`bel-cli`](https://crates.io/crates/bel-cli) executable.
